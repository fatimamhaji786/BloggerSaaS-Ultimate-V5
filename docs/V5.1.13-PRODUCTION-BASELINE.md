8. PRODUCTION SECURITY BASELINE

The following security principles are part of the V5.1.13 baseline:

Gemini Credentials

The Gemini API key must remain server-side as a Cloudflare secret.

The Gemini API key must NOT be placed in:

- Blogger HTML
- Blogger JavaScript
- GitHub source code
- GitHub releases
- public documentation
- browser local storage
- client-side configuration

Firebase Authentication

Authenticated AI requests must continue to use Firebase Authentication
and a valid Firebase ID token.

AI Gateway

The Blogger frontend must communicate with Gemini through the secure
Cloudflare Worker rather than directly exposing the Gemini API key.

Secrets

The following production secrets are referenced by name only:

- "GEMINI_API_KEY"
- "AI_PROXY_TOKEN"

Their values are intentionally excluded from this document.

Security Status:

🟢 PRESERVED
