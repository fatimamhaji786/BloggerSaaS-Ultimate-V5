6. Development Principles
6.1 Production Safety
All development work must remain separated from the frozen V5.1.13 production baseline.
6.2 Controlled Changes
Functional changes should be introduced in small, understandable increments.
Each significant change should have:
a defined purpose
a defined scope
a test requirement
a descriptive commit
a rollback consideration
6.3 Preserve Working Functionality
The existing AI gateway has already been validated.
Therefore, V5.1.14 must not unnecessarily replace or redesign working production components.
6.4 Security First
Secrets must never be committed to GitHub.
The following must remain protected:
Gemini API key
Cloudflare secrets
Firebase private credentials
authentication tokens
internal security tokens
Client-side code must not contain the Gemini API key.
