20. Regression Protection

Every V5.1.14 functional change must be evaluated for regression risk.

Mandatory regression test

LIVE AI END-TO-END TEST PASSED
Response: LIVE_GATEWAY_OK

If the test fails

The development process must immediately:

1. Stop further feature work.
2. Identify the regression.
3. Record the failure.
4. Isolate the affected change.
5. Correct the development implementation.
6. Repeat the affected tests.
7. Repeat the live AI end-to-end test.
8. Confirm "LIVE_GATEWAY_OK".
9. Only then continue development.

30. Rollback Policy

The primary rollback reference remains V5.1.13.

If V5.1.14 causes a critical production failure:

1. Stop further deployment activity.
2. Identify the failure.
3. Protect evidence and diagnostics.
4. Assess severity.
5. Initiate rollback if required.
6. Restore the validated V5.1.13 production state.
7. Verify gateway health.
8. Verify "LIVE_GATEWAY_OK".
9. Record the incident.
10. Correct V5.1.14 in development before another release attempt.
